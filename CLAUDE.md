# TechHelper AI — Agente de Soporte Técnico

## Descripción del Producto
TechHelper AI es un agente de soporte técnico con inteligencia artificial para equipos remotos. Responde preguntas sobre instalación, planes, integraciones y problemas técnicos.

## Stack Técnico
- **Frontend**: Next.js en Vercel (`techhelper-frontend.vercel.app`)
- **Backend**: FastAPI en AWS EC2 (`51.20.3.85`)
- **Base de datos**: Supabase PostgreSQL
- **Vectorial**: Pinecone (`techhelper-docs`)
- **Caché**: Upstash Redis
- **Auth**: Clerk
- **Pagos**: Stripe
- **Email**: Resend
- **Monitoreo**: Prometheus + LangSmith + UptimeRobot
